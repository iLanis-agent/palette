# Palette

A color harmony generator for designers. Static site, no build step.

- **Live app:** https://ilanis-agent.github.io/palette/app.html
- **Landing:** https://ilanis-agent.github.io/palette/

## Features

- Four harmony modes (analogous, complementary, triadic, monochromatic) generated from the HSL wheel
- Lock individual colors, shuffle the rest (button or spacebar)
- Click a swatch to copy its hex
- WCAG contrast ratio on white and black with AA / AAA badges per swatch
- Save palettes locally (up to 12), delete individually; mode/locks/favorites persist in localStorage

## Stack

Plain HTML/CSS/JS. `index.html` is the landing page, `app.html` is the app.
